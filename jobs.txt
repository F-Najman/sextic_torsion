# One job per line: log file TAB command TAB closing marker [TAB expected result (ERE)]
# Every command is run from the repository root and its output replaces the named log.
# verify_all.sh treats a job as successful only if the command exits 0 and the closing line
# of the log is the marker (optionally followed by a space and details).  The closing line is
# the last non-blank line, ignoring carriage returns, a trailing "Script done on ..." line
# written by script(1), and trailing lines that consist of a CPU time only (Magma prints the
# time on a line of its own after a sequence).
# If a fourth column is present, the log must also match that extended regular expression.
#
# A command of the form "archived: ..." marks a log that no single command regenerates: an
# interrupted run, or a continuation loaded by hand into a running Magma session.  The text
# after "archived:" records how the log was produced.  verify_all.sh does not run these; the
# README says how to reproduce the computation behind each of them.
#
# Provenance of the parameters.  The committed logs were produced by the original runs,
# with copies of these scripts that differ from the ones here at most in file paths (see
# README, "Provenance of the committed logs").  Most commands are recorded in the original
# material, or are determined because the script takes no parameters.  The following are not
# recorded anywhere; their parameters were read off the log (SETUP, QLIST, CC, SURVIVORS and
# SIEVE_RESUME_DONE lines, RATIONAL_TWO_START) and the driver from the file times, and MemGB is
# then left at the driver's default (memory limits do not change the output):
#   logs/finite_fields/torsion_F2_49_51_55_75_77_85.log, logs/sieve/X1_32_p3.log,
#   logs/sieve/X1_34_p3.log, logs/sieve/X1_38_p3.log, logs/sieve/X1_39_p2.log,
#   logs/sieve/X1_50_p3.log, logs/sieve/X1_33_p5_resume.log, logs/sieve/X1_2_22_p3_resume.log,
#   logs/sieve/X1_2_26_p3.log, logs/sieve/X1_2_28_p3.log (only Qs; 7 resp. 13 would be
#   discarded by the driver anyway), logs/sieve/X1_49_p3_resume.log,
#   logs/classes/X1_32_p3_class_membership.log, logs/rr/X1_21_F2_double_cusp_validation.log
#   (DirectCheck), logs/homology/J1_57_two_torsion.log and logs/homology/J1_49_T2.log
#   (MatrixFile; it only adds the export), and the archived lines marked [inferred].
#
# Logs that come from the original run and must be regenerated with the path-edited script
# (the script differs from the one that produced the log only in a file path):
#   logs/counts/gl2_point_counts.log, logs/counts/short_sieves.log,
#   logs/counts/X1_42_p5.log, logs/counts/X1_2_24_p5.log, logs/counts/X1_35_p3_verify.log
